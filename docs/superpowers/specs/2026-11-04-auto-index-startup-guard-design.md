# 自动索引启动连接保护

按用户已确定的方案，在建立 MCP 会话前，通过本地 CLI 读取 `auto_index`。

- `false`：保持自动连接；`true`：状态栏显示 `CBM: Connect`，等待手动连接。
- 读取失败或输出不是布尔值：同样保持未连接，并显示原因。
- 复用连接/重试命令；手动连接时重新读取配置，开启或未知时提示可能触发后台索引，确认后连接。
- 检查和连接期间显示 `CBM: Connecting…`；连接完成后保留现有 Ready、Index、Error 等状态。
- 未受信任工作区不执行 CLI 或建立连接；授予信任后仍执行自动连接保护。
- 只读取共享配置；不增加持久化的连接授权或后台轮询。
- 扩展释放后，尚未完成的配置读取不得继续启动 MCP 会话。

改动范围：运行时探测、扩展初始化与手动连接入口、状态模型、回归测试、用户文档和 0.1.6 安装包。
